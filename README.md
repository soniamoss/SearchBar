# SearchBar Phase 1 Prototype

SearchBar is a bare-bones website prototype for the CS514 database product project. It includes a branded homepage, About page, Blog page, product prototype page, and Project Hub containing links to the Phase 1 deliverables.

## Run locally

Open `index.html` in a browser. For a local server, run this folder with any simple static server, such as VS Code Live Server.

## Replace before submitting

1. Replace the placeholder team names and role descriptions on `about.html`.
2. Replace the GitHub link on `deliverables.html` with the team repository.
3. Replace the technical-document placeholder with the hosted PDF link.
4. Add each team member's blog paragraph to `blog.html`.
5. Add the final presentation link when it is ready.

## Next development stage

The `product.html` page currently uses sample data so the prototype can be demonstrated immediately. The next stage can replace the sample cards with data retrieved from Supabase and add authentication, reviews, and database-backed filtering.
